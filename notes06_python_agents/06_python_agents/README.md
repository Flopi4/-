## Виконання роботи

У ході лабораторної роботи було створено модульну архітектуру застосунку інтелектуальних агентів. Проєкт реалізовано безпосередньо з використанням інструментів `google-adk` та `python-dotenv` для безпечного керування API-ключами через файли конфігурації.

### 1. Структура проєкту
Проєкт організовано у наступну ієрархію папок та файлів:
* `06_python_agents/` — коренева папка проєкту.
* `pyproject.toml` та `poetry.lock` — конфігураційні файли проєкту.
* `tools/common_tools.py` — загальні утиліти для аналізу та форматування тексту.
* `my_first_agent/agent.py` — базовий агент для визначення часу.
* `math_agent/agent.py` — математичний агент для геометричних обчислень.
* `student_helper/agent.py` — мультиагентний помічник студента з ООП.

## Опис розроблених агентів

### 1. Базовий агент (`my_first_agent`)
Реалізує функціонал взаємодії з LLM моделлю `gemini-2.5-flash`. До агента підключено кастомний інструмент (Tool) `get_current_time`, який динамічно повертає системний час у форматі `HH:MM:SS`.

### 2. Математичний агент (`math_agent`)
Спеціалізований асистент для розрахунку параметрів геометричних фігур. 
* **Базові інструменти:** `calculate_rectangle_area`, `calculate_circle_area`, `calculate_cube_volume`.
* ⭐ **Виконане індивідуальне завдання:** Додано унікальний інструмент `calculate_cylinder_volume` для розрахунку об'єму циліндра за формулою $V = \pi r^2 h$ з валідацією вхідних даних (радіус та висота мають бути > 0).

### 3. Помічник студента (`student_helper`)
Мультиагентна система, що виступає в ролі ментора з ООП програмування. До нього інтегровано:
* Власні інструменти: `explain_concept` (пояснення термінів залежно від рівня студента) та `check_syntax` (валідація коду).
* Спільні інструменти (імпортовані з `tools.common_tools`): `count_words` та `format_text` для обробки великих текстових запитів від студентів.
