# Звіт до роботи

**Тема:** Класи та об'єкти. Основи ООП у Python.

**Мета роботи:** Навчитись працювати з класами та їх основними конструкціями в мові Python, засвоїти використання методів, властивостей та магічних методів.

У ході лабораторної роботи було реалізовано об'єктно-орієнтовану модель у Jupyter Notebook. Виконання розбито на етапи:

* **Етап 1: Основи та конструктор**

* **Етап 3: Декоратори та статика**

## Висновок:
1. **Що зроблено:** Повністю реалізовано програму для демонстрації ключових принципів ООП.
2. **Результат:** Програма успішно проходить усі тести, магічні методи коректно взаємодіють з об'єктами.
